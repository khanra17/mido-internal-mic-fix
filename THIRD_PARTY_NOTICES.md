# Third-party notices

The installer generates a replacement for the device's existing
`/vendor/etc/mixer_paths_mtp.xml`. It preserves the copyright and BSD-3-Clause
notice attributed to The Linux Foundation in that file.

No vendor XML, audio samples, vendor binaries, APKs or diagnostic logs are shipped
in the source repository or release ZIP. The generated XML stays on the device.
The module scripts, patch, tests and documentation are Apache-2.0.
